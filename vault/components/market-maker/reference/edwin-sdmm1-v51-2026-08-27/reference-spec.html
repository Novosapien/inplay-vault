Reference price, t-zero through settlement

The single valuation path for all 170 team companies. One formula prices the IPO, every week of secondary trading, and settlement — the differences are only which observations have arrived. Build against novo_engine.py; a port is correct when it passes test_engine.py.

settlement VT = $5·W + $2.50·Ties (NFL) + A — accrual; nothing pays until the regular season ends
price P(t) = DF(t) · [ 5·ΣP(wing) + 2.50·ΣP(tieg) + 2.50·Σvg ] − RC(t)
state r ~ N(m, S) in points · dg = ri − rj + H · P(win) = Φ( dg / √(ς² + Var dg) )
Banked legs use actual results and printed ad dollars at face (× DF). Unresolved legs use the posterior. The live game is $5 × WPlive, exactly. Everything is linear-Gaussian, so every update below is one exact Kalman step and the price is a martingale in closed form — there is no drift to tune away.

03

The five update channels

Each is one observation on the shared rating (or brand) state via the same Kalman step: m ← m + S·h·ν/(h′Sh + σ²obs), S ← S − S·h·h′·S/(h′Sh + σ²obs), with h = +1 home / −1 away.

EventObservation ofObs. noiseRules
Posted spread (weekly board)dg1.5 ptsPRIMARY channel — 100× the information of a result. Never price off the raw spread as Φ(S/ς): filter it, then price off the posterior (raw is ~$0.50/game biased).
Final margindg15 ptsbanks the $5 (or tie) and re-rates the team in one step. The evidence is the margin vs the number, not the W/L.
Live projectiondgς²/elapsedweight rises 0→1 through the game; equals the final-margin update at the whistle, so nothing steps. The live game itself is priced $5 × WPlive — no shrinkage, ever.
Tuesday ad printlogit capture0.35 lgupdates BRAND state only. An ad number never moves a football rating (one-way cut; the win leg is 2.4× the ad leg and amplifies any leakage).
Injury reportrating shift—−INJURY_PTS on that team + variance widening. Applies to ANY team in the league — an opponent's QB moves your price. Invalidates posted spreads it post-dates (flag for re-post; a stale spread fights the injury, wrong sign).
Engineering requirements, non-negotiable

State must be replayable: store observations, rebuild the posterior from the prior on read. In-place updates double-apply on repeated ticks (−$1.18 per repeat, measured) and the maker ticks many times a minute. One observation per game: final margin supersedes live projection supersedes spread. Timestamps on the board feed: they decide whether an injury post-dates a spread.

04

Marketing — retention model

Per Supplement A, confirmed Aug 27.

  • Each game carries a $2.50 pool. A team's capture is its own number vs the field (0.6 brand + 0.4 performance), clamped 20–80%. The two captures in a game need not sum to 1 — the platform retains the residual (~35.8% league-wide on the NFL reconstruction sheet).
  • Revenue accrues; the Tuesday report is an information event, not a distribution — the share never goes ex-anything. A print at projection is roughly price-neutral; a beat re-rates the forward brand leg, not just the banked cash.
  • Both sides' captures print independently; carry them per-team, never as complements.

06

Port acceptance

A port is accepted when test_engine.py passes 31/31 against it: t-zero reconciliation to the penny, martingale bias < $0.01 over the predictive of every event type (spread, margin, ad print), zero drift over 200 repeated ticks, exact settlement identity, no whistle step, stale-spread invalidation, and the behaviour set above. Out of scope of this document: the quoting layer (width, pull rule, position cap, skew — inputs sized, not specified here) and final constants estimation, which awaits the freeze file and game history.
