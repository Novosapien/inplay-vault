Sportradar data platform LIVE

The sports-data backbone: one service owns the Sportradar relationship for the whole platform

Where it stands

Deployed and serving production traffic. The service fronts Sportradar for NFL and NCAA across 18 data domains — schedules, standings, rosters, players, injuries, news and AP editorial, win probabilities, rankings, leaders, draft, transactions and more — with caching so the platform never exposes Sportradar's rate limits to user traffic. It was the most actively developed service in July.

Delivered

  • Production deployment with infrastructure-as-code, continuous integration, and a strong automated test suite (500+ tests, 80% coverage gate).
  • The live-game worker (real-time state, pipeline, publisher for the websocket layer) is built and deployed alongside the API.
  • First-game go-live runbook and live testing protocol written.
  • Performance audit completed 29 July; news-image delivery identified as the main cost and already being optimised.
  • Entity-ID join model established: one ID ties play-by-play, news, headshots and win probability together across the app.

In flight

  • Live-game switch-on — the production worker currently points at Sportradar's simulation host with no live games configured. This is deliberate; flipping to live feeds is a scheduled, separately approved change before the first game.
  • Production entitlements with Sportradar — win probabilities in production, the v2 bulk endpoint, and quota levels are being driven with Sportradar (Scott/David); a consolidated list of blocked products has been sent.
  • Feed tier — the in-app Gamecast runs on the licensed media feeds; Sportradar's faster betting-side feeds are licensed to sportsbooks only. Mitigation agreed: the probability API rides the faster path, and the market maker consumes probabilities directly, so pricing never lags the visuals. Cody continues to lobby for betting-feed access.
  • Weekly internal data drop: InPlay produces remaining-season win probabilities (Sportradar does not compute them); Edwin supplies the model and the Wednesday refresh.

Next

  • Close the entitlement list with Sportradar ahead of the IPO window.
  • Schedule and execute the live-feed switch-on with the first-game runbook.
  • Keep the news/image performance work rolling before season traffic.
