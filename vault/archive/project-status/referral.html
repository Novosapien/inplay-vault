Referral programme LIVE

The growth engine: give 500, get 1,000 — every code a permanent identity

Where it stands

The referral programme has been live since early July, first through the challenge website with full web KYC, now feeding the live app. 85 referrals were recorded by 6 July, before the app itself was in the store.
  • Lifetime-unique codes, collision-tested to roughly one billion users; a code never regenerates.
  • QR page, share sheet, referral links with deep-linking, and referrer/referee tracking with crediting gated on KYC approval.
  • Preset bonus windows (weekly 1.5×, event 3× days) built and driven from the campaign calendar.
  • Referral links now point at the App Store and auto-fill the code, replacing the website route.

Delivered

  • System built and demoed 5 June; live launch aligned to the 4 July weekend with the existing ~600 signups emailed.
  • Referral wallet design agreed: separate, uncapped balance that refills the trading wallet back to 100K when it drops below 25K.
  • Prize-model restructure (24 June): payouts gated on participation with a maximum of three criteria; referrals are not a hard gate — they earn their own leaderboard with its own prize.
  • Nudge feature agreed so referrers can prompt pending signups.

In flight / open

  • Final prize qualification criteria — the participation line (minutes, trades, education completion), payout schedule and multiplier mechanics need a focused session to close.
  • Cash-eligibility rules — minimum referrals plus location capture were proposed; the complete rule set, and whether it applies per withdrawal or per season, is undecided.
  • Referral → buying-power mechanism — an API approach has been proposed to tZERO in place of a daily file; awaiting their assessment.
  • Social engagement credits (follows, likes, shares, surveys): value per action and anti-gaming rules not yet defined — phase 3.
  • Donor / group accounts (university alumni pools) require securities-law clearance before any build.

Next

  • Close the prize-criteria session with InPlay ahead of the IPO campaigns.
  • Confirm the buying-power API with tZERO so referral dollars can reach the trading wallet from day one of secondary trading.
